# Дом мудрости

Сайт с рассказами об учёных исламского мира VIII–XVI веков: аль-Хорезми, Бируни, Ибн Сина, Улугбек и другие — в том числе учёные Центральной Азии: Юсуф Баласагуни и Махмуд Кашгари (Кыргызстан), аль-Фараби, аль-Джаухари и Мухаммад Хайдар Дулати (Казахстан), Абу Наср Мансур, аль-Фергани и Бируни (Узбекистан).

- **Фронтенд** — `public/`: HTML, CSS и JS-модули без сборки. Страницы: список с поиском и фильтрами, рассказ об учёном с обсуждением, хронология, «О проекте». Есть светлая и тёмная темы.
- **Бэкенд** — `server/`: Node.js, Express и встроенный в Node SQLite (`node:sqlite`). Отдаёт API и статические файлы.
- **Тексты** — `data/scholars.json`. При каждом запуске база пересобирается из этого файла, а комментарии читателей сохраняются в `data/site.db`.
- **Главная** — кинематографичная заставка: кадры из фильмов сменяют друг друга с медленным наездом, поверх — золотая пыль, вращающийся восьмиконечный орнамент и название, проявляющееся по буквам. Ниже — «Кинозал» с портретами учёных и карточки с постерами, которые появляются при прокрутке.
- **Фильмы** — у каждого учёного короткий фильм (`#/film/<slug>`, около полутора минут): вопрос-крючок и портрет героя, немного о его жизни, одно-два открытия в 3D-анимации, которая шаг за шагом показывает, как он это сделал (как аль-Хорезми достраивал квадрат, как Бируни измерил Землю с горы, как устроены часы-слон аль-Джазари), и наследие. Кадры идут с движением камеры, частицами в воздухе и киношной обработкой; под голос звучит музыка в ладу хиджаз; субтитры подсвечивают слова по мере произнесения.
  - `data/films.json` — сценарии: для каждой части закадровый текст (`say`), заголовок, кадры (`photos`) и 3D-анимация открытия (`scene`, `animate`);
  - `data/voiceover.json` — крючок и представление героя в начале фильма;
  - `data/shots.json` — раскадровка: описания кадров для нейросети, движение камеры (`m`), частицы (`fx`), крупная надпись (`fact`) и портрет учёного;
  - 3D-анимации — `public/js/film/scenes/`, список — `scenes/index.js`.
  - 3D-учёные — `public/js/film/figure.js`: фигура с шарнирами (ходит, поднимает астролабию к глазу, показывает рукой, пишет, работает руками), у каждого учёного свой облик (`LOOKS`). В анимациях открытий учёный — «ведущий» сбоку кадра (`cast.js`), а в сценах Бируни (`scenes/biruni.js`: два визирования вершины, подъём на гору, угол наклона горизонта, радиус Земли), секстанта Улугбека и крыльев аль-Джаухари он действует внутри сцены.
- **Озвучка** — нейроголос Microsoft «Svetlana» через [edge-tts](https://github.com/rany2/edge-tts) с таймингами слов для субтитров. Голос кэшируется в `data/audio/`, так что сеть нужна только при первом озвучивании. Без Python сервер берёт голос macOS «Milena» (`say`), а если нет и его — фильм читает голос браузера.
- **Кадры** — `public/media/shots/`. Их рисует локально нейросеть RealVisXL V5 Lightning (Stable Diffusion XL), карты глубины строит Depth Anything V2 (`tools/gen_shots.py`). Это художественная реконструкция, о чём фильм предупреждает на заставке.

## Запуск

Нужен Node.js 22.13 или новее.

```sh
npm install
npm start          # http://localhost:3000
npm run dev        # с автоперезапуском при изменении кода
npm test           # тесты API
npm run setup      # нейроголос: создаёт .venv и ставит edge-tts (нужен Python 3)
npm run narration  # заранее озвучить все фильмы (иначе — при первом просмотре)
```

Кадры уже лежат в `public/media/shots/`. Чтобы перерисовать их после правки `data/shots.json` или `data/films.json` (нужно ~8 ГБ под модели; на Apple M1 Pro — около 30 секунд на кадр), запустите команды ниже. Рисуются только кадры, которые показывают фильмы; портрет рисуется в двух вариантах (`portrait-1.v1.jpg`, `portrait-1.v2.jpg`) — чтобы выбрать другой, скопируйте его поверх `portrait-1.jpg`.

```sh
npm run setup:shots
npm run shots                    # рисует новые и изменённые кадры, потом карты глубины
npm run shots -- --only ulugbek  # только один фильм
```

Переменные: `PORT`, `DB_FILE`; голос — `NARRATOR_ENGINE` (`edge` или `say`), `NARRATOR_VOICE` (например, `ru-RU-DmitryNeural` — мужской голос), `NARRATOR_RATE` (`+5%`), `NARRATOR_PITCH` (`-2Hz`), `NARRATOR_PYTHON`.

## Публикация

Сайт опубликован на Cloudflare: https://dom-mudrosti.urpaq.workers.dev

Это статическая копия без сервера: `npm run build:static` собирает её в `dist/` — ответы API сохраняются JSON-файлами, поиск и фильтры работают в браузере, копируются озвучка и кадры фильмов. Обсуждение (комментарии) требует сервера и в статической копии скрыто. Обновить опубликованный сайт: `npm run deploy` (нужен вход в Cloudflare: `npx wrangler login`).

## API

| Запрос | Что возвращает |
|---|---|
| `GET /api/meta` | области науки и эпохи с количеством учёных |
| `GET /api/scholars?q=&field=&era=&sort=chronology\|name` | список с поиском и фильтрами |
| `GET /api/scholars/:slug` | полный рассказ, число комментариев, соседи по хронологии |
| `GET /api/scholars/:slug/film` | сценарий фильма: части, тексты, кадры, сцены, ссылки на озвучку |
| `GET /api/narration/:id.mp3` | озвучка одной части (только для текстов из фильмов; `.m4a` — для голоса macOS) |
| `GET /api/narration/:id.json` | тайминги слов этой части для субтитров |
| `GET /api/scholars/:slug/comments` | комментарии, новые сверху |
| `POST /api/scholars/:slug/comments` | добавить комментарий `{ "author", "body" }`; не больше 5 за 10 минут с одного IP |

## Как добавить учёного

Добавьте запись в `data/scholars.json` по образцу существующих: `fields` и `era` берутся из списков в начале файла. Перезапустите сервер. Ошибки в файле (неизвестная область, повтор slug, пустой рассказ) сервер покажет при запуске.

## Об источниках

Тексты написаны по общеизвестным историческим сведениям и не цитируют книгу M. Bayrakdar «İslam Bilim Adamları». Её стоит использовать для сверки и углублённого чтения. Предания и спорные рассказы вынесены в блок «Предание или факт?».
